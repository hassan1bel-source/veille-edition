# veille-edition
Répertorie tous les évènements autour du livre qui ont eu lieu entre 2020 et 2026. Tiens aussi compte des évènements en rapport avec l'imprimerie, l'achat des droits, les fellowship d'éditeur, les arts graphiques autour du livre et la Bande dessinée. Je souhaiterais créer une application de veille qui va avoir plusieurs fonctionnalités
